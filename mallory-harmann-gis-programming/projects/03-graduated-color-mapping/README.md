# Graduated Color Mapping Tool

**Tools:** Python, ArcPy, ArcGIS Pro

A custom Python toolbox that applies a graduated-color renderer to a selected layer using a chosen numeric field and classification settings. The coursework implementation demonstrates parameter validation, map-layer selection, classification, renderer configuration, progress messaging, and saving an updated ArcGIS Pro project.

## Files

- `GraduatedColorRenderer.pyt` — ArcGIS Pro Python toolbox
- `graduated_color_mapping.py` — supporting coursework script
- `screenshots/` — captured map and tool execution results

The original ArcGIS Pro project and geodatabase are not included because project paths and data dependencies are local to the original environment.
