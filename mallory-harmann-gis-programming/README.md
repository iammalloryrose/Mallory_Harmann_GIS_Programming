# GIS Programming & ArcGIS Pro Portfolio

Selected Python and ArcPy projects developed during graduate GIS programming coursework. The repository emphasizes geoprocessing automation, reusable ArcGIS Pro tools, cartographic automation, and raster analysis.

## Featured projects

| Project | Technologies | Summary |
|---|---|---|
| [Garage–Building Proximity Analysis](projects/01-garage-building-proximity/) | Python, ArcPy, File Geodatabase | Projects point data, buffers locations, intersects building footprints, and exports results |
| [Parameterized Geoprocessing Toolbox](projects/02-parameterized-geoprocessing-toolbox/) | Python, ArcPy, Python Toolbox (.pyt) | Packages the proximity workflow as a configurable ArcGIS Pro tool |
| [Graduated Color Mapping Tool](projects/03-graduated-color-mapping/) | Python, ArcPy, ArcGIS Pro | Applies a graduated-color renderer to a selected map layer |
| [Raster Terrain Processing](projects/04-raster-terrain-processing/) | Python, ArcPy Spatial Analyst | Creates a multiband composite, hillshade, and slope surface |

## Environment

These scripts require a licensed ArcGIS Pro installation with the relevant ArcPy capabilities and, where noted, Spatial Analyst. They are coursework examples rather than standalone cross-platform Python packages.

## Academic context

Projects were developed for GIS programming coursework. The source scripts are preserved as portfolio examples; input datasets and ArcGIS project files are not redistributed where their provenance, licensing, or portability could not be confirmed.
